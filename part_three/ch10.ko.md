# End와 Coend

범주의 사상에 여러 직관을 붙일 수 있지만 객체 `a`에서 `b`로 가는 사상이 있으면 두 객체가 어떤 식으로든 "관련"되어 있다는 데는 모두 동의할 수 있다. 사상은 어떤 의미에서 이 관계의 증명이다. 사상이 곧 관계인 모든 부분 순서 범주에서 분명하게 보인다. 일반적으로 두 객체 사이의 같은 관계에는 "증명"이 여럿일 수 있고, 이들이 hom-set이라는 집합을 이룬다. 객체를 바꾸면 객체 쌍에서 "증명" 집합으로 가는 사상을 얻는다. 첫 인자에는 반변이고 둘째에는 공변인 functorial한 사상이다. 범주의 객체 사이에 전역적인 관계를 세우는 것으로 볼 수 있으며 hom-functor가 이를 설명한다.

<pre>C(-, =) :: C<sup>op</sup> × C -> Set</pre>

일반적으로 이런 functor는 범주 객체 사이의 관계를 세우는 것으로 해석할 수 있다. 관계가 서로 다른 두 범주 *C*, *D*를 포함할 수도 있다. 그런 관계를 설명하는 functor의 시그니처는 다음과 같고 profunctor라고 한다.

<pre>p :: D<sup>op</sup> × C -> Set</pre>

수학자는 `C`에서 `D`로 가는 profunctor라고 말하며 방향 반전에 주목해 빗금 화살표를 기호로 사용한다.

<pre>C ↛ D</pre>

profunctor를 *증명과 관련된 관계*로 생각할 수 있다. 집합의 원소가 관계의 증명을 나타낸다. `p a b`가 비어 있으면 `a`와 `b` 사이에는 관계가 없다. 관계가 대칭일 필요는 없음을 기억하자.

endofunctor가 컨테이너라는 발상을 일반화한 직관도 유용하다. profunctor 값 `p a b`는 타입 `a`의 원소를 키로 하는 `b`의 컨테이너로 볼 수 있다. 특히 hom-profunctor의 원소는 `a`에서 `b`로 가는 함수다.

하스켈에서 profunctor는 함수 쌍을 끌어올리는 `dimap` 메서드를 갖춘 두 인자 타입 생성자 `p`로 정의한다. 첫 함수는 "반대" 방향으로 간다.

```haskell
class Profunctor p where
    dimap :: (c -> a) -> (b -> d) -> p a b -> p c d
```


profunctor의 functoriality는 `a`가 `b`와 관련 있다는 증명이 있고 `c`에서 `a`로, `b`에서 `d`로 가는 사상이 있으면 `c`가 `d`와 관련 있다는 증명을 얻는다고 말한다. 또는 첫 함수는 새 키를 이전 키로 번역하고 둘째는 컨테이너 내용물을 수정한다고 생각할 수 있다.

한 범주 안에서 작용하는 profunctor에서는 대각 원소 `p a a`에서 많은 정보를 뽑아낼 수 있다. 사상 쌍 `b->a`, `a->c`가 있으면 `b`가 `c`와 관련 있음을 증명할 수 있다. 더 나아가 사상 하나로 대각 밖의 값에 도달할 수 있다. 예를 들어 사상 `f::a->b`가 있으면 쌍 <f, id<sub>b</sub>>를 끌어올려 `p b b`에서 `p a b`로 갈 수 있다.

```haskell
dimap f id pbb :: p a b
```

또는 쌍 <id<sub>a</sub>, f>를 끌어올려 `p a a`에서 `p a b`로 갈 수 있다.

```haskell
dimap id f paa :: p a b
```

## Dinatural 변환

profunctor는 functor이므로 표준 방식으로 그 사이의 자연 변환을 정의할 수 있다. 하지만 많은 경우 두 profunctor의 대각 원소 사이 사상만 정의해도 충분하다. 대각 원소를 비대각 원소에 잇는 두 방법을 반영한 가환 조건을 만족하면 이런 변환을 dinatural 변환이라고 한다. functor 범주 <pre>[C<sup>op</sup> × C, Set]</pre>의 원소인 두 profunctor `p`, `q` 사이 dinatural 변환은 다음 사상족이다.

<pre>α<sub>a</sub> :: p a a -> q a a</pre>

모든 `f::a->b`에 대해 다음 도형이 가환한다.

![](images/end.jpg)

이는 자연성 조건보다 엄밀히 약하다는 점에 주목하자. `α`가 [C<sup>op</sup> × C, Set]의 자연 변환이라면 위 도형은 자연성 사각형 둘과 profunctor `q`가 합성을 보존한다는 functoriality 조건 하나로 구성할 수 있다.

![](images/end-1.jpg)

[C<sup>op</sup> × C, Set]의 자연 변환 `α` 성분은 객체 쌍 α<sub>a b</sub>로 인덱싱된다. 반면 dinatural 변환은 각 profunctor의 대각 원소만 보내므로 객체 하나로 인덱싱된다.

## End

이제 "대수"에서 범주론의 "미적분"이라 볼 수 있는 것으로 나아갈 준비가 되었다. end와 coend의 미적분은 전통적인 미적분에서 발상과 일부 표기까지 빌려온다. 특히 coend는 무한합 또는 적분으로, end는 무한곱과 비슷하게 이해할 수 있다. Dirac 델타 함수와 닮은 것까지 있다.

end는 functor를 profunctor로 바꾼 극한의 일반화다. 뿔 대신 wedge가 있다. wedge의 밑면은 profunctor `p`의 대각 원소들이 이룬다. 꼭짓점은 객체이며 여기서는 **Set** 값 profunctor를 다루므로 집합이다. 옆면은 꼭짓점을 밑면의 집합들로 보내는 함수족이다. 이 함수족을 반환 타입에 대해 다형적인 함수 하나로 생각할 수 있다.

<pre>α :: forall a . apex -> p a a</pre>

뿔과 달리 wedge 안에는 밑면의 꼭짓점을 잇는 함수가 없다. 하지만 앞에서 보았듯 *C*의 임의의 사상 `f::a->b`가 주어지면 `p a a`와 `p b b`를 모두 공통 집합 `p a b`에 연결할 수 있다. 따라서 다음 도형이 가환하도록 요구한다.

![](images/end-2.jpg)

wedge 조건이라고 하며 다음처럼 쓸 수 있다.

<pre>p id<sub>a</sub> f ∘ α<sub>a</sub> = p f id<sub>b</sub> ∘ α<sub>b</sub></pre>

하스켈 표기로는:

<pre>dimap id f . alpha = dimap f id . alpha</pre>

이제 보편적 구성을 진행해 `p`의 end를 보편 wedge로 정의할 수 있다. 집합 `e`와 함수족 `π`가 있고, 꼭짓점 `a`와 함수족 `α`를 가진 다른 모든 wedge에 대해 모든 삼각형을 가환하게 하는 유일한 함수 `h::a->e`가 존재한다.

<pre>π<sub>a</sub> ∘ h = α<sub>a</sub></pre>

![](images/end-21.jpg)

end의 기호는 "적분 변수"를 아래첨자에 둔 적분 기호다.

<pre>∫<sub>c</sub> p c c</pre>

`π`의 성분을 end의 사영 사상이라고 한다.

<pre>π<sub>a</sub> :: ∫<sub>c</sub> p c c -> p a a</pre>

*C*가 항등 이외의 사상이 없는 이산 범주이면 end는 범주 *C* 전체에 걸친 `p`의 모든 대각 항목의 전역 곱일 뿐이다. 더 일반적인 경우 end와 이 곱이 동등자를 통해 관련된다는 것을 나중에 보이겠다.

하스켈에서 end 공식은 전칭 한정자로 직접 옮겨진다.

<pre>forall a. p a a</pre>

엄밀히는 `p`의 모든 대각 원소의 곱일 뿐이지만 매개변수성 때문에 wedge 조건이 자동으로 만족된다. [별도 블로그 글](https://bartoszmilewski.com/2017/04/11/profunctor-parametricity/)에서 설명하겠다. 임의의 함수 `f :: a -> b`에 대해 wedge 조건은 다음과 같다.

<pre>dimap f id . pi = dimap id f . pi</pre>

타입 주석을 붙이면:

<pre>dimap f id<sub>b</sub> . pi<sub>b</sub> = dimap id<sub>a</sub> f . pi<sub>a</sub></pre>

방정식 양변의 타입은 다음과 같다.

<pre>Profunctor p => (forall c. p c c) -> p a b</pre>

`pi`는 다형 사영이다.

```haskell
pi :: Profunctor p => forall c. (forall a. p a a) -> p c c
pi e = e
```

타입 추론이 `e`의 올바른 성분을 자동으로 고른다.

뿔의 모든 가환 조건을 자연 변환 하나로 표현했듯 모든 wedge 조건을 dinatural 변환 하나로 묶을 수 있다. 그러려면 상수 functor Δ<sub>c</sub>를 모든 객체 쌍을 객체 `c` 하나로, 모든 사상 쌍을 그 객체의 항등 사상으로 보내는 상수 profunctor로 일반화해야 한다. wedge는 그 functor에서 profunctor `p`로 가는 dinatural 변환이다. Δ<sub>c</sub>가 모든 사상을 항등 함수 하나로 끌어올린다는 사실을 알면 dinaturality 육각형이 wedge 마름모로 줄어든다.

**Set** 이외의 대상 범주에도 end를 정의할 수 있지만 여기서는 **Set** 값 profunctor와 그 end만 생각한다.

## 동등자로서의 End

end 정의의 가환 조건은 동등자로 쓸 수 있다. 먼저 함수 둘을 정의하자. 이 경우 수학 표기가 덜 친절해 보여 하스켈 표기를 사용한다. 이 함수들은 wedge 조건의 서로 만나는 두 가지에 대응한다.

```haskell
lambda :: Profunctor p => p a a -> (a -> b) -> p a b
lambda paa f = dimap id f paa

rho :: Profunctor p => p b b -> (a -> b) -> p a b
rho pbb f = dimap f id pbb
```

두 함수 모두 profunctor `p`의 대각 원소를 다음 타입의 다형 함수로 보낸다.

```haskell
type ProdP p = forall a b. (a -> b) -> p a b
```

두 함수의 타입은 다르다. 하지만 `p`의 모든 대각 원소를 한데 모은 거대한 곱 타입을 만들면 타입을 통일할 수 있다.

```haskell
newtype DiaProd p = DiaProd (forall a. p a a)
```

함수 `lambda`와 `rho`는 이 곱 타입에서 출발하는 사상 둘을 유도한다.

```haskell
lambdaP :: Profunctor p => DiaProd p -> ProdP p
lambdaP (DiaProd paa) = lambda paa

rhoP :: Profunctor p => DiaProd p -> ProdP p
rhoP (DiaProd paa) = rho paa
```

`p`의 end는 이 두 함수의 동등자다. 동등자는 두 함수가 같은 가장 큰 부분집합을 고른다는 것을 기억하자. 여기서는 wedge 도형이 가환하는 모든 대각 원소의 곱의 부분집합을 고른다.

## End로 나타낸 자연 변환

end의 가장 중요한 예는 자연 변환의 집합이다. 두 functor `F`, `G` 사이의 자연 변환은 `C(F a, G a)` 형태의 hom-set에서 고른 사상족이다. 자연성 조건이 없다면 자연 변환의 집합은 이 모든 hom-set의 곱일 뿐이다. 실제로 하스켈에서는 그렇다.

```haskell
forall a. f a -> g a
```

하스켈에서 작동하는 이유는 자연성이 매개변수성에서 따라 나오기 때문이다. 하지만 하스켈 밖에서는 그런 hom-set을 가로지르는 모든 대각 단면이 자연 변환을 만드는 것은 아니다. 그런데 다음 사상은 profunctor다.

```haskell
<a, b> -> C(F a, G b)
```

따라서 그 end를 연구하는 것이 타당하다. 다음은 wedge 조건이다.

![](images/end1.jpg)

집합 ∫<sub>c</sub> C(F c, G c)에서 원소 하나를 고르자. 두 사영은 이 원소를 어떤 특정 변환의 두 성분으로 보낸다. 다음처럼 부르자.

<pre>τ<sub>a</sub> :: F a -> G a
τ<sub>b</sub> :: F b -> G b</pre>

왼쪽 가지에서는 hom-functor로 사상 쌍 <id<sub>a</sub>, G f>를 끌어올린다. 이런 끌어올림은 앞 합성과 뒤 합성을 동시에 하는 것으로 구현한다고 기억할 것이다. τ<sub>a</sub>에 작용하면 다음을 얻는다.

<pre>G f ∘ τ<sub>a</sub> ∘ id<sub>a</sub></pre>

도형의 다른 가지는 다음을 준다.

<pre>id<sub>b</sub> ∘ τ<sub>b</sub> ∘ F f</pre>

wedge 조건이 요구하는 둘의 등식은 `τ`의 자연성 조건일 뿐이다.

## Coend

예상대로 end의 쌍대를 coend라고 한다. wedge의 쌍대인 cowedge로 구성한다. cow-edge가 아니라 co-wedge라고 발음한다.

![](images/end-31.jpg)

*날카로운 소?*

coend의 기호는 "적분 변수"를 위첨자에 둔 적분 기호다.

<pre>∫ <sup>c</sup> p c c</pre>

end가 곱과 관련 있듯 coend는 쌍대곱 또는 합과 관련 있다. 이 점에서는 합의 극한인 적분과 비슷하다. 사영 대신 profunctor의 대각 원소에서 coend로 내려가는 주입이 있다. cowedge 조건이 없다면 profunctor `p`의 coend는 `p a a`, `p b b`, `p c c` 등 중 하나라고 말할 수 있다. 또는 coend가 집합 `p a a`인 어떤 `a`가 존재한다고 말할 수 있다. end 정의에 사용한 전칭 한정자가 coend에서는 존재 한정자로 바뀐다.

그래서 의사 하스켈로 coend를 다음처럼 정의한다.

```haskell
exists a. p a a
```

하스켈에서 존재 한정자를 인코딩하는 표준 방법은 전칭 한정된 데이터 생성자를 사용하는 것이다.

```haskell
data Coend p = forall a. Coend (p a a)
```

어떤 `a`를 골랐든 타입족 `p a a`의 값으로 coend를 구성할 수 있어야 한다는 논리다.

end를 동등자로 정의할 수 있듯 coend는 *coequalizer*로 설명할 수 있다. 가능한 모든 함수 `b->a`에 대해 `p a b`의 거대한 쌍대곱 하나를 취해 모든 cowedge 조건을 요약할 수 있다. 하스켈에서는 존재 타입으로 표현한다.

```haskell
data SumP p = forall a b. SumP (b -> a) (p a b)
```

`dimap`으로 함수를 끌어올리고 profunctor `p`에 적용해 이 합 타입을 평가하는 방법이 둘 있다.


```haskell
lambda, rho :: Profunctor p => SumP p -> DiagSum p
lambda (SumP f pab) = DiagSum (dimap f id pab)
rho    (SumP f pab) = DiagSum (dimap id f pab)
```


여기서 `DiagSum`은 `p`의 대각 원소의 합이다.

```haskell
data DiagSum p = forall a. DiagSum (p a a)
```

두 함수의 coequalizer가 coend다. `DiagSum p`에서 같은 인자에 `lambda`나 `rho`를 적용해 얻은 값들을 동일시해 coequalizer를 얻는다. 인자는 함수 `b->a`와 `p a b`의 원소로 이루어진 쌍이다. `lambda`와 `rho`를 적용하면 타입 `DiagSum p`의 서로 다를 수도 있는 두 값을 만든다. coend에서는 이 값을 동일시해 cowedge 조건이 자동으로 만족되게 한다.

집합에서 관련된 원소를 동일시하는 과정을 형식적으로 몫 취하기라고 한다. 몫을 정의하려면 반사적이고 대칭적이며 추이적인 관계인 *동치 관계* `~`가 필요하다.

```haskell
a ~ a
if a ~ b then b ~ a
if a ~ b and b ~ c then a ~ c
```


그런 관계는 집합을 동치류로 나눈다. 각 동치류는 서로 관련된 원소로 이루어진다. 각 동치류에서 대표 하나를 골라 몫집합을 만든다. 고전적인 예는 정수 쌍과 다음 동치 관계로 유리수를 정의하는 것이다.

```haskell
(a, b) ~ (c, d) iff a * d = b * c
```

동치 관계임을 쉽게 확인할 수 있다. 쌍 `(a, b)`는 분수 `a/b`로 해석하며 공약수가 있는 분수들을 동일시한다. 유리수는 그런 분수들의 동치류다.

극한과 쌍대극한을 논의할 때 hom-functor가 연속, 즉 극한을 보존한다고 했음을 기억할 수 있다. 쌍대적으로 반변 hom-functor는 쌍대극한을 극한으로 바꾼다. 이 속성은 각각 극한과 쌍대극한의 일반화인 end와 coend로 일반화할 수 있다. 특히 coend를 end로 바꾸는 매우 유용한 항등식을 얻는다.

<pre>Set(∫ <sup>x</sup> p x x, c) ≅ ∫<sub>x</sub> Set(p x x, c)</pre>

의사 하스켈로 보자.

<pre>(exists x. p x x) -> c ≅ forall x. p x x -> c</pre>

존재 타입을 받는 함수가 다형 함수와 동등하다고 말한다. 그런 함수는 존재 타입에 인코딩될 수 있는 타입 중 어느 것이든 처리할 준비가 되어 있어야 하므로 완벽하게 말이 된다. 합 타입을 받는 함수가 합에 있는 각 타입의 핸들러 하나씩을 가진 case 문으로 구현되어야 한다는 원리와 같다. 여기서는 합 타입이 coend로, 핸들러족이 end 또는 다형 함수로 바뀐다.

## 닌자 요네다 보조정리

요네다 보조정리에 나오는 자연 변환의 집합을 end로 인코딩하면 다음 표현을 얻는다.

<pre>∫<sub>z</sub> Set(C(a, z), F z) ≅ F a</pre>

쌍대 공식도 있다.

<pre>∫ <sup>z</sup> C(a, z) × F z ≅ F a</pre>

이 항등식은 Dirac 델타 함수의 공식과 매우 닮았다. `δ(a - z)`는 엄밀히는 분포이며 `a = z`에서 무한한 첨점을 갖는다. 여기서는 hom-functor가 델타 함수 역할을 한다.

두 항등식을 함께 닌자 요네다 보조정리라고 부르기도 한다.

두 번째 공식을 증명하려고 두 객체가 동형일 필요충분조건은 그 hom-functor가 동형이라는 요네다 매장의 결과를 사용하겠다. 즉 다음 타입의 자연 변환:

```haskell
[C, Set](C(a, -), C(b, =))
```

이 동형일 때 그리고 그때만 `a ≅ b`다.

증명하려는 항등식의 왼쪽을 임의의 객체 `c`로 가는 hom-functor 안에 넣는 것으로 시작한다.

<pre>Set(∫ <sup>z</sup> C(a, z) × F z, c)</pre>

연속성 논증을 사용해 coend를 end로 바꿀 수 있다.

<pre>∫<sub>z</sub> Set(C(a, z) × F z, c)</pre>

이제 곱과 지수 사이의 수반을 이용한다.

<pre>∫<sub>z</sub> Set(C(a, z), c<sup>(F z)</sup>)</pre>

요네다 보조정리를 사용해 "적분을 수행"하면 다음을 얻는다.

<pre>c<sup>(F a)</sup></pre>

이 지수 객체는 다음 hom-set과 동형이다.

```haskell
Set(F a, c)
```

마지막으로 요네다 매장을 이용해 다음 동형에 도달한다.

<pre>∫ <sup>z</sup> C(a, z) × F z ≅ F a</pre>

## Profunctor 합성

profunctor가 관계, 더 정확히는 `p a b`라는 집합이 `a`와 `b`가 관련 있다는 증명 집합을 나타내는 증명 관련 관계라는 발상을 더 탐구하자. 관계 `p`, `q`가 둘 있으면 합성을 시도할 수 있다. 중간 객체 `c`가 존재해 `q b c`와 `p c a`가 모두 비어 있지 않으면 `p` 다음에 `q`를 합성한 관계를 통해 `a`가 `b`와 관련 있다고 하자. 새 관계의 증명은 개별 관계 증명의 모든 쌍이다. 존재 한정자가 coend에 대응하고 두 집합의 데카르트 곱이 "증명 쌍"에 대응한다고 이해하면 다음 공식으로 profunctor의 합성을 정의할 수 있다.

<pre>(q ∘ p) a b = ∫ <sup>c</sup> p c a × q b c</pre>

이름을 조금 바꾼 `Data.Profunctor.Composition`의 동등한 하스켈 정의는 다음과 같다.

```haskell
data Procompose q p a b where
  Procompose :: q a c -> p c b -> Procompose q p a b
```


자유 타입 변수인 `c`가 자동으로 존재 한정되는 일반화된 대수적 데이터 타입, 즉 GADT 문법을 사용한다. 커링하지 않은 데이터 생성자 `Procompose`는 따라서 다음과 동등하다.

```haskell
exists c. (q a c, p c b)
```

이렇게 정의한 합성의 단위는 hom-functor다. 닌자 요네다 보조정리에서 곧바로 따라 나온다. 따라서 profunctor가 사상 역할을 하는 범주가 있는지 묻는 것이 타당하다. 답은 그렇지만 profunctor 합성의 결합법칙과 항등 법칙이 모두 자연 동형을 무시할 때만 성립한다는 주의점이 있다. 법칙이 동형을 무시할 때 성립하는 범주를 bicategory라고 하며 2-범주보다 일반적이다. 따라서 객체는 범주, 사상은 profunctor, 사상 사이의 사상인 2-cell은 자연 변환인 bicategory **Prof**가 있다. 더 나아갈 수도 있다. profunctor뿐 아니라 범주 사이의 일반 functor도 사상으로 있기 때문이다. 사상 종류가 둘인 범주를 double category라고 한다.

profunctor는 하스켈 lens 라이브러리와 arrow 라이브러리에서 중요한 역할을 한다.
